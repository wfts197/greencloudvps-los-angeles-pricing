**加购有上限。** 内存、CPU、SSD 的加购价都是 $3/单位/月（1GB 内存、1 核、10GB SSD），但官网写明加购上限等于现有配置——4GB 内存的机器最多再加 4GB。想大幅扩容，升级套餐比加购更合理。
